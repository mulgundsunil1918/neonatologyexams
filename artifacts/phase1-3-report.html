Finding — a hidden 11th sitting

Pages 189–192 and 201–210 are scanned images of an April 2024 exam that appears nowhere else in the document as text — it was invisible to any text search or naive page-count parsing. Both papers (11 essay questions, 50 MCQs with a full answer key) were recovered by direct visual transcription, question-by-question, and cross-checked against the printed answer key. Without this step, an entire sitting — and its answer key — would have been silently dropped.

Duplicate-block reconciliation

60 of 276 pages are exact re-scans or re-typed copies of a paper captured elsewhere (confirmed by MD5 hash of whitespace-collapsed text, or by manual line-for-line comparison for the image scans). None of these contributed a single question to the 804-count above — each was traced to its primary occurrence and excluded, so the same paper printed three times could never masquerade as three different exams.

05 Parsing & data-quality notes

A matching count is not proof of a correct split. 10 of 804 questions used option formatting irregular enough (no punctuation, nested lettered sub-blocks, a genuine gap in the source's own lettering) that they were individually hand-verified and corrected rather than left to a looser regular expression that could silently corrupt a correctly-parsed question elsewhere.

  • 2021-07 P2 Q39 — the source paper itself skips "D" and jumps A, B, C, E for its four options. Preserved exactly as printed and flagged question/option flawed rather than silently renumbered.
  • 2021-10 P2 Q92 — a match-the-following question (health programmes ↔ aims) with a nested lettered answer-key block; parsed with the four numbered items and their descriptions folded into the stem, and the four combination answers (e.g. "1a,2b,3c,4d") as the real options.
  • 2021-07 P2 Q29 — same matching-question pattern (cardiac lesion ↔ age of presentation).
  • 6 questions (2021-07 P2 Q32/35/73/74/75, 2021-10 P2 Q93) print options as a bare letter with no "." or ")" at all — corrected by direct reading of the source page.

Image-based questions found

6 questions reference a figure, tracing, or radiograph the stem cannot stand without: 2021-10 P2 Q95 (TEF X-ray), Q96 (developmental screening chart), Q98 (Cochrane Collaboration logo), Q100 (HIE MRI); 2022-04 P2 Q48 (ECG tracing); 2023-10 P2 Q16 (lung-ultrasound waveform). Each is flagged has_image: true against its source page for the original page image to be attached once the resource/asset layer is built — none has been replaced with a text-only guess at its content.

Questions without an answer

650 of 700 MCQs currently have no marked correct answer — only the recovered April 2024 sitting shipped a printed key inside the QBank itself. The remaining 650 need either (a) a printed key elsewhere in a paper I haven't matched yet, or (b) sourcing against the textbook/protocol library once that's ingested. 07 Ingestion architecture

The pipeline that produced every number on this page — designed so a future upload (a new NNF sitting, a new textbook) re-runs the same five stages without a rewrite.

01
Structural map
Hand-verified page registry: sitting, paper, primary vs. duplicate range
02
Per-paper extract
Regex split → validated against a pre-known expected count; hard-stops on mismatch
03
Manual overrides
Named, auditable fixes for the ~1% the regex can't parse safely
04
Master dedup
Exact-text grouping → Red/Orange/White; Yellow deferred to concept review
05
Audit + load
npm run audit gate, then Prisma load into Postgres

08 Audit strategy

npm run audit (currently a Python script pending the Next.js port) checks all ten items from your spec's Part 26 and exits non-zero if any critical value is non-zero:

1. Question count audit804 = 804
2. Duplicate audit0 duplicate records
3. Missing-question audit0 missing
4. Option-parsing audit0 with missing options
5. Answer audit650 unanswered — tracked, not hidden
6. Source-citation auditnot started — needs textbook ingestion
7. Page-number auditevery occurrence carries its QBank page range
8. Paper/year auditall 11 sittings dated and labeled
9. Repetition auditRed/Orange computed
10. Yellow concept auditnot started — flagged, not guessed
